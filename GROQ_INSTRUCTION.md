# Groq API - Инструкция по настройке

## Что изменилось
Заменил OpenAI на бесплатный Groq API. Теперь помощник работает через Groq с моделью **Llama 3 70B**.

## Почему Groq лучше для тебя:
1. **Бесплатно** - 10 000 запросов/день (хватит на учебу!)
2. **Очень быстро** - быстрее OpenAI в 10 раз
3. **Мощная модель** - Llama 3 70B отлично понимает Python и русский язык
4. **Просто настроить** - 1 минута регистрации

## Как получить API ключ:

### Шаг 1: Зарегистрируйся на Groq
1. Перейди на https://console.groq.com/
2. Нажми "Sign Up" и создай аккаунт
3. Подтверди email

### Шаг 2: Получи API ключ
1. После входа перейди в раздел **API Keys**
2. Нажми **"Create API Key"**
3. Скопируй ключ (он начинется с `gsk_...`)

### Шаг 3: Добавь ключ в проект

#### Вариант A: Для локального запуска
Создай файл `.env` в корне проекта:
```
GROQ_API_KEY=твой_ключ_здесь
```

#### Вариант B: Для Render
1. Зайди в настройки проекта на Render
2. В разделе **Environment** добавь переменную:
   - Key: `GROQ_API_KEY`
   - Value: `твой_ключ_здесь`

## Как использовать помощник:

После настройки ключа:
1. Открой сайт на http://127.0.0.1:8000/
2. Нажми кнопку "💬 Помощник" в правом нижнем углу
3. Задай любой вопрос:
   - "Как добавить модуль в админке?"
   - "Объясни что такое list comprehension в Python"
   - "Как работает Django ORM?"
   - "Как исправить ошибку TypeError?"

## Примеры вопросов:

### Для админки:
- "Как добавить новую тему в модуль?"
- "Где загрузить презентацию?"
- "Как связать тему с модулем?"

### Для Python:
- "Что такое декораторы в Python?"
- "Как сделать цикл for с шагом?"
- "Разница между list и tuple?"
- "Как обработать исключение?"

### Для Django:
- "Что такое миграции?"
- "Как создать кастомную админку?"
- "Разница между ModelViewSet и ListView?"

## Если ключ не работает:
- Проверь, что ключ введён правильно (начинается с `gsk_`)
- Убедись, что переменная окружения называется `GROQ_API_KEY`
- Проверь, что Groq API доступен из твоей сети
- Помощник автоматически переключится на локальный режим

## Локальный режим (без API):
Если ключ не настроен, помощник будет работать в локальном режиме с правилами - он всё равно ответит на основные вопросы про админку и обучение.
